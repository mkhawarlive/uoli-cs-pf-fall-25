# Object Oriented Programming — Fall 2026

This repository contains course materials, examples, lab tasks, assignments,
and supporting resources for the Programming Fundamentals course offered by
the Department of Computer Science, University of Loralai.

## Course Information

- **Course:** Object Oriented Programming
- **Semester:** Fall 2026
- **Department:** Computer Science
- **University:** University of Loralai
- **Instructor:** Muhammad Khawar Abbas

## Repository Contents

- Lecture examples
- C++ source-code examples
- Lab tasks
- Assignments
- Practice problems
- Supporting course material

## Programming Language

The examples and assignments in this repository primarily use **C++**.

## Instructions for Students

1. Review the relevant lecture material before attempting a task.
2. Write and test the programs independently.
3. Follow the specified file-naming conventions.
4. Make meaningful commits when updating your work.
5. Do not copy code from other students.
6. Be prepared to explain and modify your submitted programs.

## Academic Integrity

Students must submit their own work. Copying code, sharing completed solutions,
or submitting code without understanding it may result in disciplinary action
and loss of marks.
